# 国家综合性消防救援队伍网络学院 · 挂课助手题库

本仓库用于存放「国家综合性消防救援队伍网络学院挂课助手」的**课程答案库**，供脚本在答题时读取。

- 题库文件：[`cfri-bank.json`](./cfri-bank.json)
- 原始地址（raw）：`https://raw.githubusercontent.com/csca-668/cfri-bank/main/cfri-bank.json`
- 镜像（raw 不可达时脚本会自动使用）：`https://cdn.jsdelivr.net/gh/csca-668/cfri-bank@main/cfri-bank.json`

---

## 一、文件结构（v18 起）

```json
{
  "__courses__": {
    "courses": {
      "4830cff1-5087-4be4-8e2d-5589018e923a": {
        "id": "4830cff1-5087-4be4-8e2d-5589018e923a",
        "no": 11,
        "name": "用“防消宣”一体化思维加强基层消防安全治理",
        "list": [
          { "t": 1, "no": 1, "a": "C" },
          { "t": 1, "no": 2, "a": "C" },
          { "t": 1, "no": 3, "a": "D" },
          { "t": 1, "no": 4, "a": "D" },
          { "t": 2, "no": 1, "a": "ABC" },
          { "t": 2, "no": 2, "a": "ABC" },
          { "t": 3, "no": 1, "a": "正确" },
          { "t": 3, "no": 2, "a": "错误" }
        ],
        "n": 8,
        "ts": 1795067702
      }
    }
  }
}
```

### 字段说明

| 字段 | 含义 |
|---|---|
| `__courses__` | 固定顶层键，所有答案都在它下面 |
| `courses` | 以**课程 ID** 为键的答案表 |
| `id` | 课程 ID（与 `courses` 的键一致） |
| `no` | 该课程在本期班级里的**序号**（第几门） |
| `name` | 课程名称 |
| `list` | 该课程的**逐题答案**，已按题型、题号排序 |
| `list[].t` | 题型：`1` 单选、`2` 多选、`3` 判断 |
| `list[].no` | **该题型内的题号**，从 1 开始（与页面“单选(1/4)”一致） |
| `list[].a` | 答案：单选 `C`、多选 `ABC`、判断 `正确` / `错误` |
| `n` | 该课程收录的题数 |
| `ts` | 收录时间（毫秒时间戳） |

> 关键点：题号是**按题型分别从 1 开始**的，所以必须用 `t + no` 定位，不能只看数组下标。

## 二、脚本如何使用这份题库

1. 启动时自动拉取本文件并合并到本地（优先 GitHub API，失败用 jsDelivr）
2. 答题时按“当前课程 ID”找到 `list`
3. 第 N 题按 `t + no` 取答案，例如：
   - 单选第 1 题 → 查 `1|1` → `C`
   - 多选第 2 题 → 查 `2|2` → `ABC`
   - 判断第 1 题 → 查 `3|1` → `正确`
4. 找不到该课程或该题时，才回退到 AI 作答（结果弹窗会提示“N 题是 AI 猜测”）

## 三、如何更新题库

在脚本面板上操作即可，不需要手动改文件：

| 按钮 | 作用 |
|---|---|
| **扫描并上传答案** | 进入班级页后点击：扫描本班所有已考完的考试 → 收割标准答案 → **上传到本仓库** |
| **拉取云端题库** | 只把本仓库的答案拉取并合并到本地（不上传） |
| **查看本期答案** | 本地查看已收录的每门课答案（缺项红色标注） |

收割完成后会弹窗显示每门课的收录情况，缺项显示为红色 `N.缺`。

## 四、历史格式（已废弃）

旧版本以“题干哈希”为键，一条记录存 `{a, n, t, q, v}`，形如：

```json
{ "c84b1052": { "a": [2], "n": 4, "t": 1, "q": "题干…", "v": ["50%"] } }
```

该结构自 v17 起已**全部清除**；脚本只识别 `__courses__`，读到旧格式会提示“云端题库格式已过期（需重新扫描上传）”。

---

## 五、注意事项

- 同一门课每次考试的题目顺序目前是固定的，因此可以用“题号 → 答案”的方式存取
- 若某题在成绩页没有可判定的标准答案（例如答错且接口未标注正确项），该题会缺失，弹窗中显示为红色 `N.缺`，答题时回退 AI
- 本仓库为公开仓库，仅存放答案数据，不含账号信息
